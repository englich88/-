УСТАНОВКА НА GITHUB PAGES
1. Распакуйте архив.
2. Откройте репозиторий https://github.com/englich88/stalker-pda
3. Замените старые файлы новыми файлами из архива в корне репозитория.
4. Commit changes.
5. Сайт: https://englich88.github.io/stalker-pda/

ВАЖНО: это макет. Кнопки работают только на экране, реального обмена с ОВЕН ПР200 нет. Для подключения нужны точное исполнение контроллера, интерфейс связи, адреса Modbus-регистров и карта входов/выходов. Защиты должны быть реализованы независимо в контроллере и аппаратной схеме.
